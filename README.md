# Фитнес-клуб

Десктопное приложение для автоматизации работы фитнес-центра: ведение базы клиентов и абонементов, учет персонала и тренеров, расписание тренировок и управление учетными записями. Написано на C++ Builder с визуальным интерфейсом на VCL, данные хранятся в базе Microsoft Access.

## Основные возможности

### Клиенты и абонементы
- картотека клиентов с контактами и сроками действия абонементов
- учет количества оплаченных занятий и фактически посещенных тренировок
- быстрый поиск по коду, ФИО и номеру телефона
- сортировка по алфавиту и по остатку занятий (по возрастанию и убыванию)
- добавление новых клиентов и удаление записей

### Персонал и тренеры
- учет сотрудников: должность, график работы, телефон и логин
- поиск и фильтрация по ФИО, должности и логину в реальном времени
- сортировка списка по фамилии по алфавиту
- добавление и удаление сотрудников

### Записи на тренировки
- электронный журнал записей клиентов к тренерам
- фильтрация по имени клиента, телефону и выбранному тренеру
- поиск записей по дате, времени проведения и статусу тренировки

### Авторизация и доступ
- регистрация и авторизация пользователей с валидацией логина и длины пароля
- разделение отображения: администратор видит список всех пользователей системы, обычный пользователь — только свои данные
- панель управления аккаунтами: добавление пользователей, смена паролей и удаление

### Настройки интерфейса
- быстрое переключение между светлой и темной темами оформления
- настройка цвета текста и гарнитуры шрифтов для элементов формы через системные диалоги (ColorDialog, FontDialog)

## Структура проекта
- `Unit1.cpp / .h / .dfm` — главное окно с вкладками (клиенты, сотрудники, расписание, пользователи, настройки)
- `Unit2.cpp / .h / .dfm` — форма авторизации и вход в систему
- `Unit3.cpp / .h / .dfm` — форма регистрации новых пользователей
- `Project1.cbproj` — файл проекта C++ Builder
- `Project1.cpp` — точка входа в программу
- `fitness.mdb` — база данных Microsoft Access с демонстрационными данными

## Как запустить
Для запуска требуются Windows 10/11 и Embarcadero C++ Builder (RAD Studio).
1. Открыть `Project1.cbproj` в C++ Builder.
2. Убедиться, что файл `fitness.mdb` лежит в папке с проектом.
3. Запустить проект клавишей F9.
